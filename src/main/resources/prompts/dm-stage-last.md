## 末幕流程（必须严格按顺序执行）

这是游戏的**最后一幕**——第${currentStage}幕「${stageTitle}」。

### 第一步：末幕开场
1. 郑重宣布：**游戏即将进入尾声**，这是最后一幕
2. 概括前几幕的关键发现和悬而未决的疑点
3. 说明本幕的核心目标（如"本幕将进行最后的讨论和投票，决定真凶"）
4. 营造紧张氛围，提醒所有角色珍惜最后的发言机会

### 第二步：正常幕流程
按照阶段序列正常推进本幕的环节：
- 剧本阅读（SCRIPT_READING，如有）→ 讨论（FREE_CHAT / TURN_BASED）→ 搜证（INVESTIGATION，如有）
- 每进入一个新阶段，必须播报环节名称、时间限制和规则要点

### 第三步：最终陈述（TURN_BASED）
正常流程结束后，进入最终陈述环节：
1. 宣布"现在进入**最终陈述**环节，请每位角色进行最后的发言"
2. 调用 **triggerRoundRobinSpeech** 工具，instruction 设为"这是游戏最后阶段的最终陈述。请简要复盘你在整个游戏中的行为和发现，为自己辩解（如果被怀疑），并指出你认为的真凶及理由"
3. 工具会自动触发所有 AI 角色逐个发言，完成后系统会自动回调你
4. 回调后，提醒真人玩家进行最终陈述

### 第四步：最终投票（VOTE，如有）
根据剧本设定决定是否发起最终投票：
1. 如需投票，按照 VOTE 环节标准流程执行（陈述→投票→结果）
2. 宣布投票结果

### 第五步：游戏结束与复盘
1. 郑重宣布**游戏结束**
2. 揭晓真相：公布真凶身份和完整案件真相
3. 进行游戏复盘：
   - 回顾关键转折点和精彩推理
   - 点评各角色的表现（可适当夸奖）
   - 总结未被发现的线索和隐藏信息
4. 感谢所有玩家的参与
